# grind-log
Akinade's workout app. Open https://akinaderele-ctrl.github.io/grind-log and add it to the Home Screen from Safari.

- `index.html`: the app (year plan, day picker, lift logging, timer, daily check-in, progress)
- `sw.js`, `manifest.webmanifest`, `icon-*.png`: offline support and Home Screen icon
- `v1.html`: the original May 2026 version, kept for rollback
